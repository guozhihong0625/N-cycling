# N-cycling

## Reproducible workflow for microbial nitrogen-cycling analysis in WWTP upgrading impacted rivers

This repository contains the R scripts and associated analysis workflows used in the study:

**"Interpretable AutoML Reveals WWTP Upgrading Drives Incomplete Denitrification and Nitrogen Assimilation in Tailwater-Receiving Rivers"**

The workflow integrates microbial community analysis, nitrogen-cycling functional gene characterization, taxonomic assignment, machine learning interpretation, and spatiotemporal pattern visualization.

The scripts were developed to investigate how WWTP upgrading influences microbial nitrogen transformation potential and environmental sensitivity in receiving river ecosystems.
